# Examples and Reference Implementations

This directory contains reference implementations and example code.

## Reference Implementations

- `reference/giulio_julia/` - Julia reference implementations by Giulio Gasbarri
  - `matias_simu.jl` - Main simulation code
  - `opt_gaus_with_corrections_to_the_dynamics_.jl` - Optimized Gaussian dynamics
  - `other_matis.jl` - Additional implementations
  - `trial.jl` - Trial/test implementations

These reference implementations provide alternative implementations in Julia and can be useful for:
- Comparing results between Python and Julia implementations
- Understanding the mathematical formulations
- Performance benchmarking
