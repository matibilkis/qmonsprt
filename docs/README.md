## LaTeX Build Artifacts

The following LaTeX build artifacts are automatically ignored by git (see `.gitignore`):
- `*.aux`, `*.fdb_latexmk`, `*.fls`, `*.log`, `*.synctex.gz`, `*.out`, `*.toc`

These files are generated during LaTeX compilation and should not be committed to version control.
